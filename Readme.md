# ☠️ M2G Pirate
Um jogo de terminal inspirado no **Fura Pirata**, desenvolvido em **Python** 

## 🎮 Sobre o jogo

No **M2G Pirate**, os jogadores escolhem posições em um campo, a meta é não acertar o barril que o pirata está

O jogo suporta **2 até 4 jogadores**.

## Como jogar

1. Inicie o programa pelo arquivo `Menu.py`.
2. Escolha a opção **Iniciar Jogo**.
3. Informe a quantidade de jogadores.
4. Digite o nome de cada jogador.

## ☠️ Regras

* É necessário ter entre **2 e 4 jogadores**.
* Cada jogador escolhe uma posição por vez.
* Uma posição que já foi escolhida não pode ser escolhida novamente.
* O pirata é colocado aleatoriamente no início da partida.
* Ao encontrar o pirata, o jogador perde.
* o jogador com 5 pontos perde

## 🛢️ Tamanho dos barris

| Jogadores   | Barril |
| ----------- | ------ |
| 2 jogadores | 3 × 3  |
| 3 jogadores | 3 × 4  |
| 4 jogadores | 4 × 4  |
